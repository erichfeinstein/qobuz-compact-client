# Qobuz Compact Client

A local, frameless Electron wrapper for Qobuz. Its cookie session is stored
separately from Brave, so sign in once in this client.

## Controls

- `Ctrl+Shift+R`: hard reload
- `Ctrl+Shift+I`: toggle developer tools
- `Alt+F4`: close

Disable by closing the client and returning to the Brave Qobuz PWA. The theme
is local at `theme.css`.
